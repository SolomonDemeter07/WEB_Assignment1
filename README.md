# Assignment #1 - HTML & CSS Basics

## Description
This repository contains the completed tasks for Assignment #1 focusing on HTML structure and CSS styling. The project demonstrates the use of semantic tags, basic CSS properties (colors, fonts, margins, borders), classic positioning (floats), tables, forms, and multi-page navigation.

**Completed Tasks:**
* **Task 1:** Personal Webpage and Profile Card.
* **Task 2:** Warhammer 40,000 Beginner's Guide (Classic layout using `<div>` and CSS floats).
* **Task 3:** Tribute Page dedicated to John Blanche, the Godfather of Grimdark.
* **Task 4:** Student Grades Table (with merged cells) and a Feedback Form.
* **Task 5:** Midterm Project Wireframes and Sitemap for a WH40K Fandom Wiki.
